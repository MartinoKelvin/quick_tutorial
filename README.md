# 📘 Tentang Tutorial Ini

Tutorial ini mengikuti alur resmi dokumentasi Pyramid:

- Memulai aplikasi dari file tunggal → package → konfigurasi → routing.  
- DebugToolbar untuk kemudahan development.  
- View functions & advanced view classes.  
- HTML templating (Chameleon + Jinja2).  
- Static assets dan URL generation.  
- JSON renderer untuk AJAX.  
- Sessions (SignedCookie) & Logging.  
- Forms dengan Deform + Colander.  
- SQLAlchemy ORM + CLI untuk inisialisasi database.
- Full unit testing & functional testing.
